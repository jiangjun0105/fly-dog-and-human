## Key Technical Details

### Package Structure

All code in `src/digital_drosophila/` — invoked via `python -m digital_drosophila <command>`.

Critical modules:
- `network.py` — Brian2 network builders (LIF neurons, constrained synapses, Dale's law)
- `loop.py` — `CoSimulation` class (episode API: reset/step/done/get_metrics/close)
- `learning.py` — `LearningLoop` with three-factor STDP (599 lines)
- `benchmarks/` — Full evaluation framework (common, locomotion, baselines, gait, chemotaxis, navigation, plotting)
- `locomotion.py` — FlyGym interface (build_simulation, tripod gait, 66 actuators)
- `motor_adapter.py` — Spike rate → actuator positions (rate coding, 50ms window)
- `sensory_encoder.py` — Body state → neural currents (15 ascending neurons)
- `olfaction.py` — Bilateral antenna Weber-Fechner encoder
- `arenas.py` — Concentration fields (PointSource, LinearGradient, etc.)

### Performance

- CoSimulation: ~50s wall-clock per 1s simulated (50x slower than realtime)
- Brian2 runs 20 × 0.1ms steps per 2ms coupling step with FlyGym
- Full VNC (15K neurons) via PyGeNN is faster but not integrated into the loop yet

### Key Findings from Epic 5

1. Biological network produces forward motion at 0.46 mm/s (non-random, consistent)
2. **No stepping gait** — all legs grounded 100%, locomotion is "sliding"
3. Weak positive chemotaxis with olfactory input (+1.18mm toward source in 3s)
4. High path tortuosity (9.76) — lots of movement, little net displacement
5. CPG baseline: 4.46 mm/s with perfect tripod gait
6. Findings doc: `docs/findings/2026-08-15-epic5-behavioral-benchmarks.md`

### Environment

- GPU server, headless rendering via `MUJOCO_GL=egl`
- Brian2 2.10.1 (numpy codegen, CPU), PyGeNN 5.4.0 (GPU)
- FlyGym 2.1.0, MuJoCo, imageio for video
- CUDA at `/usr/local/cuda/bin/nvcc`
- neuPrint API key in `.env` as `NEU_PRINT_API_KEY`

## Epic 4.2 Plan (Next Priority)

Issue doc: `docs/issues/2026-08-15-learning-full-plasticity.md`

What to implement:
1. **Homeostatic plasticity** — `dV_th/dt = eta * (firing_rate - target_rate)` prevents
   runaway excitation or silence during learning
2. **Synaptic decay** — `dw/dt = -lambda * w` for inactive synapses (use-it-or-lose-it)
3. **Training harness** — Run 50-100 episodes with metrics logging per episode
4. **Use benchmarks** — Run `BenchmarkRunner` with `BiologicalController` after every
   N episodes to track learning curve (gait_regularity, tripod_index, forward_speed)

The existing `LearningLoop` in `learning.py` already does STDP over episodes. Epic 4.2
extends it with homeostatic mechanisms and longer training runs.

### Expected outcome

After 50+ episodes with homeostatic STDP, the network should:
- Develop some leg-lifting behavior (duty factor < 1.0)
- Show increasing gait regularity over training
- Move faster than the untrained baseline (> 0.46 mm/s)

## Epic 4.3 Plan (After 4.2)

Issue doc: `docs/issues/2026-08-15-learning-experiment.md`

The core research question: **Does biological topology accelerate learning?**

Experimental design:
- **Condition A**: Biological connectivity (connectome-derived) + STDP training
- **Condition B**: Random connectivity (same parameters, shuffled wiring) + same training
- **Measure**: Learning curves, final performance, gait metrics
- **Hypothesis**: Condition A learns faster/better

`RandomWeightController` in `benchmarks/baselines.py` already shuffles weights within
sign groups — extend this to the `LearningLoop` for training the random-topology variant.
